What we can help with

Swiss-type lathes combine tightly coordinated operations, specialist tooling and machine-specific control logic. We bring long-standing PartMaker and CAM post-development experience to reviewing, adapting and developing posts for these demanding workflows.

Sliding-headstock configurations

Guide-bush and non-guide-bush arrangements, with the machine's actual setup confirmed.

Main and sub-spindles

Front and back working, pickup and transfer sequences based on agreed machine examples.

Multiple tool groups and channels

Machine-specific gang tooling, driven tools and coordinated channel output.

Typical challenges

Examples of the issues we can investigate. The right solution depends on the exact machine, control and CAM workflow.

Output doesn't match the shop-floor method

Compare the post with known-good programs, tooling layouts and control requirements.

Synchronisation is hard to follow

Review channel structure, wait codes and operation sequencing against agreed examples.

A machine variant needs a different setup

Define the differences in axes, tooling, spindles and post options before making changes.

Technical capabilities

  • PartMaker and applicable Fusion post workflows
  • Main/sub-spindle operations and pickup sequences
  • Multi-channel program structure and synchronisation
  • Gang tools, driven tools and machine-specific tool mapping
  • Post variants, regression tests and sample NC comparisons

From review to commissioning

We start with the machine specification, controller details, CAM release and sample NC programs. We then agree the required output, develop or adjust the post and test representative cases before any planned machine prove-out.

Support is available for Autodesk Fusion, FeatureCAM, PartMaker and PowerMill where applicable to the requested work.

Support is scoped to the specific machine, control, CAM release and programming workflow; features differ between machines and CAM systems.
